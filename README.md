# World-Happiness-Index
An analytic index that gives an insight of how different metrics of well-being &amp; happiness scores vary across regions based on their indicators. The report’s main life-evaluation measure uses a 0–10 ladder question. The overall official report commonly uses three-year averages for country rankings; verify the precise definitions and year represented by our downloaded CSV before writing conclusions.

https://www.worldhappiness.report/data-sharing/

the dataset linked above contains several years pertaining data of wellness & wellbeing from different regions on various indicators
